# AI 합성 평가 도구

- `gold/manifest.json`: 사전 고정한 정답 51개와 파일 해시.
- `gold/input-plan.json`: PDF·Markdown·텍스트 각 17개 배정.
- `inputs.py`: 입력 형식 변환과 입력 계획 검증.
- `report.py`: 필수 사실·근거·미확정 판정 채점.
- `freeze_inputs.py`: 고정 입력 계획 일치 확인.
- `feature-integration-cases.json`: 기능·외부 연동용 합성 사례 6개. 기존 Node 평가 실행기는 별도 전체 프로젝트에 있습니다.
- `run.py`: 별도로 실행 중인 전체 AgentFit 서비스의 인증된 API로 유료 모델 평가를 수행하는 도구. 이 저장소만으로 전체 평가 서비스를 실행할 수는 없습니다.

자동 AI 테스트는 외부 모델을 호출하지 않습니다. 정답 사례는 합성 데이터이며 다양한 실제 기획서에 대한 정확도를 보장하지 않습니다. `report.py`의 일부 60초 판정은 과거 평가 기준이며 현재 전체 분석 제한 180초와 별도입니다. 실제 모델 평가 결과·로그·사용자 원문은 이 저장소에 포함하지 않습니다.
